# P2 — Normalization

**Day 3 (am).**

## Goal
Three messy sources become one canonical internal representation. No matching logic here.

## Build
`src/milaan/normalize/`
- `adapters/bank_hdfc.py`, `adapters/psp_razorpay.py`, `adapters/ledger.py` — each maps a schema and nothing more. A new bank format should be a new adapter, not a rewrite.
- `utr.py` — regex family for extraction, `rapidfuzz` recovery for truncated refs, emits `utr_confidence`. Never silently guess.
- `canonical.py` — Pydantic models for the unified representation
- Timezone canonicalisation to IST, once, at the boundary. The T+2 off-by-one across an IST/UTC boundary will silently shift a whole day's batch out of the date window.

## Exit gate

- `test_no_floats` still green
