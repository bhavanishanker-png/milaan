# P8 — Freeze, held-out run, narrative

**Days 13–14. What the panel actually consumes.**

## Day 13 — freeze and document
1. **Code freeze.** No tuning after this line.
2. `make verify` — batch C, **once**. Whatever it prints goes in the README. No re-runs, no adjustments, no "one small fix".
3. `README.md` — the ten sections from `docs/SPEC.md` §10, headline result table first
4. `ARCHITECTURE.md` — diagram, tier rationale, D-code → expected-tier map, and **where reality disagreed with your expectation**
5. Mine `DECISIONS.md` for the three strongest failures: expectation, symptom, diagnosis, fix, metric before and after
6. Clean-clone test: fresh venv, `make generate && make run && make evaluate` under 60 seconds. Every year, submissions die on a missing dependency.

## Day 14 — pitch and buffer
| Time | Content |
|---|---|
| 0:00–0:30 | Problem in money terms: one bank credit, forty payments, where do the paise go |
| 0:30–2:00 | Architecture — emphasise that most records never touch an LLM, and why that's the point |
| 2:00–3:30 | Live run on batch C. **Demo an escalation, not the happy path.** |
| 3:30–4:30 | Metrics: auto-resolve, false-match, ablation, threshold curve |
| 4:30–5:00 | Honest exception list, weakest classes, what's next |

Show the audit trail on screen at least once.

## Exit gate
- Clean clone runs green on a machine that never built the project
- Video under 5:00
- README leads with numbers including false-match rate
- You can answer without hesitation: why this model, why LangGraph over a plain loop, why subset-sum over an ML matcher, why 0.85

## Day 14 is buffer, not work
If you're recording for the first time on day 14, the buffer is already gone. Have a rough cut by day 13 evening.
